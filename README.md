# FoodApp — MyOnlineMeal.com

A responsive static food delivery website built with HTML and CSS.

## 🍽️ Features

- **Hero Section** — Welcome banner with a call-to-action "Order Now" button
- **Services** — Highlights three core offerings: Food Ordering, Food Catering, and Food Delivery
- **Our Clients** — Showcases partner/client logos
- **Contact Form** — Collects name, email, phone number, and message from visitors
- **Responsive Design** — Adapts layout for screens up to 1170px wide via a dedicated `phone.css` stylesheet

## 🗂️ Project Structure

```
FoodApp/
├── index.html        # Main HTML page
├── css/
│   ├── style.css     # Base styles
│   └── phone.css     # Responsive/mobile styles (max-width: 1170px)
├── img/              # Service and client logo images
├── logo.png          # Site logo
├── bg.jpg            # Background image
├── bg1.jpg           # Secondary background image
└── contact.jpg       # Contact section image
```

## 🚀 Getting Started

No build tools or dependencies required. Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/Husnain192/FoodApp.git

# Open in browser
cd FoodApp
open index.html   # macOS
# or
start index.html  # Windows
```
